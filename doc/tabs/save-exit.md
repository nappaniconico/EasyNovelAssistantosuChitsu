# 保存/終了タブ

## 画面項目
- `出力文をtxt保存`
- `設定＋出力をjson保存`
- `設定＋出力をjsonファイルから読み込む`
- `アプリの更新`
- `アプリ終了`

## 保存形式
### txt保存
- 保存先: `output/YYYYMMDD-HHMMSS.txt`
- 内容: 出力本文のみ

### json保存
- 保存先: `output/YYYYMMDD-HHMMSS.json`
- 内容:
  - 本文
  - 構成入力値
  - 生成パラメータ
  - KoboldCpp設定（モデル/layers/context）
  - undo/redo履歴

## json読み込み
- 保存済みjsonを読み込むと、本文・入力欄・パラメータ・モデル設定を復元
- json内モデルが現環境にない場合は、現在選択モデルで代替

## アプリ更新
`アプリの更新` では `git_controll.py` の `update_enacchi()` を実行します。

- `.git` がある場合のみ更新可能
- `git pull` を実行
- `uv` があれば `uv sync` を実行

更新成功時はアプリ終了を促す動作になります。

## アプリ終了
`アプリ終了` は以下を順に実行します。

1. KoboldCpp停止（メイン・圧縮用）
2. Gradio停止
3. プロセス終了

## 注意点
- `output/` は終了時クリーンアップ対象です
- 必要な出力は終了前にダウンロードしてください
