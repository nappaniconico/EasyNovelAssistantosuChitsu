# 構成タブ

## 目的
小説生成に使う構成要素を入力し、生成時に1つのプロンプトへ統合します。

## 画面項目
- `タイトル`
- `ジャンル`
- `登場人物`
- `舞台背景`
- `続きの展開`
- `ガタライズスクリプト`（生成後置換のON/OFF）
- `オリジナルのガタライズスクリプトを使用`（外部辞書読み込み）
- `自由指示文`（画面下部）

## 生成のコツ  
ローカルLLMは基本的にlong context(長文)に弱く、起承転結などの文章構成や複線回収などが苦手です。  
そのため、こうした作品全体に渡る要素は使用者側がマネジメントする必要があります。  
基本的に「続きの展開」フォームに入力された内容に従って文章が展開されますので、適宜調節して制御してあげてください。  
事前にあらすじや章構成を検討し、書き留めておきましょう。

## 生成時のプロンプト構築
`main.py` の `_build_prompt()` で、各項目を以下のラベル形式で連結します。

```text
/【指示】/...
/【タイトル】/...
/【ジャンル】/...
/【登場人物】/...
/【舞台背景】/...
/【...続きの展開...】/
/【本文】/...
```

空欄は `特になし` が入るため、未入力でも構文は崩れません。

## ガタライズ関連の挙動
- `ガタライズスクリプト` ONで、生成完了後に置換辞書を適用
- `オリジナルのガタライズスクリプトを使用` ONで、読み込んだ辞書を利用
- OFFに戻すと既定の `gscript.json` に戻ります

詳細は `doc/tabs/gscript-editor.md` を参照してください。
