# ガタライズスクリプト作成タブ

## 目的
置換辞書（ガタライズスクリプト）を編集し、生成後テキストへ適用するためのファイルを作成します。

## 画面項目
- `編集したいガタライズスクリプト`
- `変換したい言葉`
- `変換先の言葉`（`,` 区切りで複数）
- `追加する`
- `削除したい語彙`
- `選択した語彙を削除`
- `ガタライズスクリプトを保存する`

## データ形式
辞書形式は次です。

```json
{
  "置換元1": ["候補A", "候補B"],
  "置換元2": ["候補C"]
}
```

ただし保存時は `cipher.py` の `SimpleStringCipher` により、文字列要素が暗号化されます。  
そのため、見た目は通常の平文JSONではありません。

## 適用タイミング（技術仕様）
生成時の置換適用は `main.py` の `on_retry_stream()` の `finally` 節で行われます。

1. 生成テキスト（今回追加分）を `acc` に蓄積
2. `ガタライズスクリプト` がONなら辞書を走査
3. 置換元ごとに `random.choice(候補リスト)` で1候補を選択
4. `acc.replace(置換元, 候補)` を実行
5. 最終表示は `既存本文(base) + 置換後acc`

重要:
- 置換対象は「今回生成した追加分」が中心で、既存本文全体を再変換しません
- 同一置換元でも生成ごとに候補が変わるため、結果に揺らぎが出ます

## 編集処理の流れ
`gscript_edit.py` の `Gscript_editer` が担当します。

- 読み込み: `load_gsc()`（復号読み込み）
- 追加: `add_gsc()`（既存キーには候補を追記）
- 削除: `remove_from_loaded()`
- 保存: `save_to_json()`（`output/gscript*.json` に暗号化保存）

## 注意点
- ファイルは `.json` のみ読み込み対象
- `変換先の言葉` は `,` 区切りで分割されるため、語彙内に`,`を含める設計には不向きです
